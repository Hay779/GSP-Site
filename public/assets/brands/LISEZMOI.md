# Logos des marques

Déposez ici les logos officiels des marques, avec exactement ces noms de fichiers :

| Marque   | Fichier         |
|----------|-----------------|
| Vachette | `vachette.png` ✅ |
| Bricard  | `bricard.png` ✅ |
| Fichet   | `fichet.png` ✅ |
| Picard   | `picard.png` ✅ |
| DOM      | `dom.png` ✅ |
| ISEO     | `iseo.png` ✅ |
| Héraclès | `heracles.png` (à fournir) |
| ABUS     | `abus.png` (à fournir) |
| JPM      | `jpm.png` (à fournir) |
| Mottura  | `mottura.png` (à fournir) |
| Pollux   | `pollux.png` (à fournir) |
| Tordjman Métal | `tordjman.png` (à fournir) |
| Muel     | `muel.png` (à fournir) |
| Reelax   | `reelax.png` (à fournir) |

- Format conseillé : **SVG** (net à toutes les tailles). Un PNG à fond transparent
  fonctionne aussi : changez alors l'extension dans `src/data/sectionsContent.ts`
  (`logoSrc`).
- Tant qu'un fichier manque, le site affiche le nom de la marque à la place.
- Où les trouver : espace « presse » / « médias » du site du fabricant, ou auprès
  de votre distributeur.
