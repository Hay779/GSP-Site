## 4. Actions client

Rien n'est lancé sans l'accord du client. Chaque point demande une connexion, un code SMS/courrier ou une pièce justificative que seul le client peut fournir. **Hermes ne saisit jamais de code ni de mot de passe.**

1. **Accord général** : confirmer qu'on peut corriger toutes les fiches ci-dessus avec les informations de `docs/INFOS-OFFICIELLES.md`.
2. **Google** (fiche n° 1) : se connecter avec gspserrurerie13@gmail.com → https://business.google.com → fiche « Bricard Vachette Serrurerie de la République… » → Modifier le profil.
   - Site web : `https://www.serrurerierepublique.fr`
   - Nom : « Serrurerie de la République »
   - Catégorie principale : « Serrurier »
   - Description : texte court et long de INFOS-OFFICIELLES.
   - Vérifier les horaires (déjà 9h–19h, dimanche fermé).
   Une modification de nom ou de catégorie peut déclencher une revue Google : prévoir quelques jours.
3. **PagesJaunes** (fiche n° 2) : créer ou ouvrir un compte sur https://www.pagesjaunes.fr/pros → « Revendiquer ma fiche » ; Solocal peut demander un **appel, un SMS ou un courrier** de validation, et parfois une pièce d'identité ou un extrait Kbis. Le client doit saisir lui-même le code. Une fois la fiche revendiquée : nom, adresse complète, horaires, site, description, prestations.
4. **Bing Places** : https://www.bingplaces.com → se connecter → « Importer depuis Google » (une fois Google corrigé). Validation possible par SMS, appel ou courrier.
5. **Apple Plans** : https://businessconnect.apple.com avec un identifiant Apple ; validation par appel ou SMS. À faire seulement si le client a un identifiant Apple professionnel.
6. **Yelp** (fiche n° 20) : signaler que notre numéro est publié sur la fiche d'un autre établissement n'est utile que si le client le souhaite (il faudra un compte Yelp).
7. **Registres (SIREN 539 656 173)** : le client doit voir avec le gérant de l'ancienne société / son expert-comptable pour régulariser (radiation ou mention de cession). Hermes ne peut pas corriger ces registres.
8. **Chambre de métiers (CMA PACA)** : accès avec le numéro SIRET et peut-être une pièce d'identité du gérant.
9. **Comptes à créer pour les annuaires « petits »** (Cylex, Cybo, NosAvis, Hoodspot, Kompass, Yably) : une adresse e-mail de contact pour recevoir les liens de validation. L'adresse ne doit jamais être publiée sur la fiche.
